# Go Kyrgyzstan — сайт

Next.js 16 + next-intl, четыре языка (en / ru / kg / fr).

Весь контент — туры, направления, фотографии, отзывы, команда, FAQ и
контакты — приходит из Django-бэкенда в `../go_travel_back`. В самом сайте
остались только элементы интерфейса: подписи кнопок, заголовки секций,
навигация.

## Запуск

Сначала поднимите бэкенд (см. `../go_travel_back/README.md`), затем:

```bash
npm install
npm run dev
```

Адрес бэкенда задаётся переменной `API_BASE_URL` — см. `.env.example`.
По умолчанию `http://127.0.0.1:8000`.

**`npm run build` требует запущенного бэкенда**: страницы туров и направлений
пререндерятся из его API.

## Как контент попадает на сайт

`src/lib/api.ts` — единственная точка обращения к бэкенду. Ответы кешируются
на 60 секунд, поэтому правка в админке появляется на сайте в течение минуты
без пересборки. Картинки бэкенд отдаёт относительными путями, слой API делает
их абсолютными — иначе `next/image` не сможет их забрать.

Тексты интерфейса живут в `src/messages/*.json` и переводятся вручную;
контентные тексты туров и направлений переводятся в админке.

## Галерея

`src/components/ui/Lightbox.tsx` — сетка фотографий, каждая открывается на
весь экран: стрелки по бокам, клавиши ← → и Esc, счётчик и подпись из alt-текста.
Используется в блоке «Фото с маршрута» на странице тура, в галерее направления
и в ленте на главной.

Оверлей рендерится порталом в `body`: у шапки стоит `backdrop-filter`, а он
делает элемент containing block для `position: fixed` — вложенный оверлей
схлопнулся бы до размеров шапки.

## Заявки

Форма отправляется в `/api/inquiry`. Роут кладёт лид в amoCRM (форма 1744102,
`src/lib/amo.ts`) и дублирует его в Django, чтобы заявку было видно в админке.
Источник правды — amoCRM; ошибка записи в CMS не ломает отправку.

## Адаптив

Мобильная версия повторяет композицию десктопа, а не перестраивается: те же
многоколоночные сетки, шрифты и отступы масштабируются через `clamp()`
(токены `--fs-*`, `--h2`, `--section-py`, `--grid-gap` в `src/app/globals.css`).

Осторожно с Tailwind v4: `text-[var(--fs-xs)]` неоднозначен между размером и
цветом и молча не генерируется. Нужен хинт — `text-[length:var(--fs-xs)]`.
